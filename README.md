# Physical AI & Humanoid Robotics Book

This repository contains the complete source for the "Physical AI & Humanoid Robotics" book, designed as a comprehensive guide for developing intelligent humanoid robotic systems.

## Overview

This book covers the complete development lifecycle for humanoid robotics, including:

- Physical AI fundamentals
- ROS 2 development
- Simulation environments (Gazebo, Isaac Sim)
- Vision-Language-Action (VLA) systems
- Hardware specifications
- Capstone project implementation

## Structure

The book is organized into several modules:

1. **Foundations**: Core concepts of Physical AI
2. **Module 1**: ROS 2 fundamentals
3. **Module 2**: Digital twin and simulation
4. **Module 3**: Isaac AI platform
5. **Module 4**: Vision-Language-Action systems
6. **Capstone**: Complete project specification
7. **Hardware**: Workstation and robot specifications
8. **Reference**: Glossary and templates

## Building the Documentation

This book is built using Docusaurus, a modern static website generator.

### Installation

```bash
npm install
```

### Local Development

```bash
npm start
```

This command starts a local development server and opens up a browser window. Most changes are reflected live without having to restart the server.

### Build

```bash
npm run build
```

This command generates static content into the `build` directory and can be served using any static contents hosting service.

### Deployment

The site can be deployed to various platforms:

- GitHub Pages
- Netlify
- Vercel
- Any static hosting service
