# Support

Thank you for using the Physical AI & Humanoid Robotics book! This document provides resources and guidance for getting help with the content and examples in this book.

## How to Get Help

### Documentation
First, please check our documentation:
- [Complete Table of Contents](./docs/toc.md)
- [Setup Guide](./docs/setup-guide.md)
- [FAQ](./docs/faq.md) (coming soon)
- [Troubleshooting Guide](./docs/troubleshooting.md) (coming soon)

### Issues and Questions
For specific issues or questions:

1. **Search existing issues** - Check if your question has already been answered in the issue tracker
2. **Read the FAQ** - Many common questions are answered in the frequently asked questions section
3. **Check the troubleshooting guide** - Common problems and solutions are documented here
4. **Create a new issue** - If you can't find an answer, create a new issue with detailed information

## Types of Support

### Content Questions
For questions about the book content, concepts, or explanations:
- Open an issue in the repository
- Provide specific details about the chapter/module and your question
- Include any relevant code snippets or error messages

### Technical Issues
For technical problems with code examples or setup:
- Check the troubleshooting guide first
- Ensure you've followed the setup guide correctly
- Include your environment details (OS, ROS version, etc.)
- Provide detailed error messages and steps to reproduce

### Feature Requests
For suggestions to improve the book:
- Open an issue with the "enhancement" label
- Describe the feature and its benefits
- Explain how it would help readers

## Community Resources

### Contributing

## When to Contact Maintainers Directly

Contact the maintainers directly only for:
- Security vulnerabilities (use SECURITY.md guidelines)
- Urgent issues that require immediate attention
- Questions about project direction or governance

## Support Expectations

### Response Times
- Initial response: Within 48 hours
- Detailed response: Within 1 week for complex issues
- Updates on ongoing issues: Every 2 weeks

### What We Support
- Content accuracy and clarity
- Code examples and exercises
- Setup and configuration issues
- Documentation improvements

### What We Don't Support
- Production system deployment
- Custom code implementations beyond book examples
- Third-party software issues unrelated to the book
- Issues not following our support guidelines

## Providing Effective Support Requests

When creating an issue or asking for help, please include:

1. **Clear, descriptive title** - Summarize your issue in the title
2. **Environment details** - OS, ROS version, hardware, etc.
3. **Steps to reproduce** - How to recreate the issue
4. **Expected vs. actual behavior** - What you expected vs. what happened
5. **Error messages** - Any relevant error messages or logs
6. **Code snippets** - Relevant code that's causing issues
7. **Screenshots** - When helpful to visualize the issue

## Self-Help Resources

- Re-reading the relevant chapters
- Checking the troubleshooting guide
- Looking for similar issues in the repository
- Testing with the provided examples
- Verifying your environment setup
